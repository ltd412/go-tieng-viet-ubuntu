Tính năng

Làm kỹ những chỗ bộ gõ tiếng Việt trên Linux hay trục trặc.

1

Telex và VNI

Đặt dấu kiểu mới (hòa, thủy) hoặc kiểu cũ (hoà, thuỷ), tùy bạn chọn.

2

Gõ không gạch chân

Chữ hiện ra ngay như đang gõ bình thường, ở hầu hết ứng dụng.

3

Hoàn tác bằng phím lặp

Như Unikey và macOS: ff ra f, eee ra ee.

4

Gõ dấu tự do

Gõ dấu sau cả từ cũng đúng: tieengs, duwocj, baya.

5

Nhận biết từ tiếng Anh

Từ không phải âm tiết tiếng Việt như class, windows được giữ nguyên.

6

Cài đặt theo ứng dụng

Ví dụ tắt tiếng Việt trong terminal để gõ lệnh không bị đổi chữ. Có sẵn nút thêm các terminal phổ biến.

Chạy tốt ở

Đã kiểm thử trên ứng dụng thật, gõ nhanh 40 phím mỗi giây.

Terminal (gnome-terminal) Chrome và thanh địa chỉ VS Code Files (Nautilus) Ứng dụng GTK3 và GTK4 Qua ibus-portal

Cài đặt

Cài xong, trình cài đặt tự restart ibus và chọn Gõ Tiếng Việt làm bộ gõ, nên gõ được ngay.

Cách 1: file .deb

Tải file ở trang Releases rồi chạy:

# trong thư mục chứa file .deb
sudo apt install ./ibus-gtv_*_amd64.deb

Cách 2: build từ mã nguồn

Cần Rust (cargo) và các gói phụ thuộc:

git clone https://github.com/ltd412/go-tieng-viet-ubuntu.git
cd go-tieng-viet-ubuntu
cargo build --release
sudo scripts/install.sh

Đổi giữa tiếng Anh và tiếng Việt bằng Super + Space. Mở cài đặt bằng cách tìm “Gõ Tiếng Việt” trong Activities. Chưa thấy bộ gõ? Chạy ibus restart, rồi /usr/lib/ibus-gtv/gtv-activate để thêm vào Input Sources. Hướng dẫn đầy đủ nằm trong README.
