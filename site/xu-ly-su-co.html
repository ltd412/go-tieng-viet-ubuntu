Bật bộ gõ bằng dòng lệnh

Trình cài đặt thường tự làm các bước này. Nếu cần làm tay, chạy trong phiên đồ họa của bạn (không cần sudo):

ibus write-cache && ibus restart          # nạp lại danh sách engine
ibus list-engine | grep gtv               # phải thấy gtv-telex và gtv-vni

# Thêm vào Input Sources (giữ các bộ gõ đang có), rồi chọn nó
gsettings get org.gnome.desktop.input-sources sources
gsettings set org.gnome.desktop.input-sources sources "[('xkb', 'us'), ('ibus', 'gtv-telex')]"
gsettings set org.gnome.desktop.input-sources current 1
Giá trị sources phải gồm cả những bộ gõ mà gsettings get vừa in ra. current là vị trí, tính từ 0, của gtv-telex trong danh sách đó.

Giới hạn

  • Chỉ thử trên Ubuntu 24.04, X11, IBus 1.5.29, GNOME 46. Wayland không nhận diện được ứng dụng nên luôn dùng chế độ mặc định (backspace). Chưa test.
  • Chưa thử: Firefox (snap), Qt/KDE, JetBrains, Warp, Lark, Postman, Cursor. Nếu một ứng dụng lỗi, xem bảng ở trên.
  • select và forward-keys chỉ để thử nghiệm.
  • Từ tiếng Anh trùng với âm tiết Việt hợp lệ (is ra í, or ra ỏ) vẫn bị biến đổi, như Unikey và bộ gõ macOS. Chuyển input source hoặc gõ đôi phím dấu để hoàn tác.
  • Chưa có phím tắt bật/tắt tiếng Việt riêng cho từng ứng dụng lúc đang gõ. Dùng danh sách trong cài đặt hoặc đổi input source.
  • Chưa có Esc-to-revert và phím tắt bao dấu bằng ngoặc.
